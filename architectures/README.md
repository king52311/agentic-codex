# 架构方案库

本目录用于沉淀可跨项目复用的业务架构方案。

## 使用方式

- 新项目开始前，先查这里是否已有相似业务方案。
- 新功能设计时，优先复用已有方案的数据流、权限模型、同步机制和页面组织方式。
- 复用时只复制思路，不直接照搬业务字段。
- 每个方案应说明适用场景、功能特点、推荐结构、关键表、接口形态、前端页面和验证方式。
