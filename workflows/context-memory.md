# 上下文记忆通用流程

## 读取顺序

项目如果存在上下文文件，Agent 进入项目、插件重载、会话恢复或上下文压缩后，应先读取：

1. 项目专属 Agent 入口，如 `AGENTS.md`
2. 通用 Agent 入口，如 `agentic-codex/AGENT.md`
3. 当前上下文摘要，如 `CURRENT_CONTEXT.md`
4. 项目历史记录，如 `PROJECT_HISTORY.md`
5. 必要时再读归档历史

若项目 `AGENTS.md` 已指定更严格顺序，以项目规则为准。

## 写入要求

完成重要改动、提交、发布、线上操作、数据修复或复杂排查后，应更新项目上下文记录。

记录内容保持摘要化：

- 改了什么。
- 执行了什么。
- 验证结果。
- 剩余风险或部署提醒。

不要把大段日志、原始 HTML、超长 JSON 直接写入主历史文件。
