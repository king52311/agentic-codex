# Git 提交流程通用规则

## 提交前

- 查看 `git status --short`，确认变更范围。
- 区分用户已有改动和本次 Agent 改动，不回滚他人改动。
- 有未纳入版本控制但属于本次任务的文件，要加入提交。
- 提交前运行与改动范围匹配的验证。

## Commit Message

- 使用项目要求的语言；无要求时优先简洁中文。
- 描述结果，不写空泛动作。
- 示例：

```text
完善通用 Agent 规则仓库
修复考勤统计部门筛选
新增地下水登记导出任务表
```

## Push

- push 前确认当前分支和远端。
- push 失败时先读错误原因，不盲目覆盖远端。
- 不使用破坏性命令处理冲突，除非用户明确要求。
