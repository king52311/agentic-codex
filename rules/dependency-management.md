# 依赖变更通用规范

## 变更原则

- 新增依赖前先确认标准库、项目已有依赖或轻量实现是否足够。
- 不因局部小需求引入重量级依赖。
- 新增、删除、升级、降级依赖后，必须同步修改依赖声明文件。

## 结果说明

依赖有变化时，结果里至少说明：

- 变更了哪些依赖包。
- 修改了哪些依赖文件。
- 测试环境和正式环境是否需要同步安装。

## 导入校验

- Python 新增或调整导入后，至少运行相关文件的 `py_compile` 或 import 级校验。
- TypeScript / JavaScript 新增或调整导入后，运行项目约定的构建或类型检查。
- 不能只看编辑器不报错就结束。
