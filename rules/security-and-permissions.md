# 安全与权限通用规范

## 权限原则

- 前端只控制入口展示，后端接口必须再次校验权限。
- 管理后台、用户管理、角色权限、部门数据、文件上传、外部调用都属于高风险改动。
- 普通用户数据范围要明确：本人、部门、业务归属或全量。
- 管理员能力要通过权限点、角色或项目既有规则控制。

## 敏感信息

- 不提交密钥、Token、账号密码、Cookie、真实连接串。
- 日志和历史记录中不要写入完整敏感凭据。
- 新增环境变量时要说明默认值策略和部署同步范围。

## 外部系统

- 外部 API 调用要处理鉴权失败、限流、超时、响应结构变化。
- 生产数据修复前先查影响范围。
- 批量写入外部系统应优先支持 dry-run。
